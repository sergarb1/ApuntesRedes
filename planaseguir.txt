## Protocolo workflow Excalidraw (Windows, puerto 3001)

- `$env:EXPRESS_SERVER_URL = 'http://127.0.0.1:3001'` (el 3000 lo usa otra instancia).
- Pestaña abierta: `Start-Process "http://127.0.0.1:3001/"` si falla con exit 4.
- JSON en `/tmp` o carpeta temporal → `add fichero.json` → esperar ~3 s → `screenshot --out x.png`
  → REVISAR PNG (leer la imagen) → corregir si hace falta → `export --out f.excalidraw` +
  `screenshot --format svg --out f.svg` → `clear --yes` → siguiente.
- NUNCA paralelizar clear/import/export.
- Tras crear/editar: `node scripts/fix-fonts.mjs && node scripts/fix-text-align.mjs` →
  si tocan `.excalidraw`, **re-exportar el SVG** (`import f.excalidraw --replace` +
  `screenshot --format svg`) → `npm run check:diagrams` → 0 fallos.
- Reglas diseño: fontFamily 3, texto ≥16 (títulos 20–28), fillStyle solid,
  paleta azul #2563eb / teal #4ecdc4 / rojo #e03131 (fondos #eff6ff/#f0fdf4/#ffe3e3),
  shapes ≥120×60, gaps 40–80, rejilla 20px, texto suelto textAlign left,
  bound labels center; flechas SIEMPRE con startElementId/endElementId.
- Checker: título = texto libre con mayor fontSize y token del nombre base
  (quitar `uXX-`, sin acentos); bound labels pad ≥6 horiz / ≥4 vert; SVG ≥1KB.
- Iconos: `docs/excalidraw-icons.md`. Borrar `.tmp-*` de `public/diagrams/` antes de commitear.

## Reglas aprendidas (no romper)

- Solo se quitan ASCII que el diagrama sustituye LITERALMENTE (configs, salidas de
  consola y ASCII de detalle se quedan).
- Flechas: requieren x, y (y points) aunque tengan startElementId/endElementId;
  el cliente ancla al punto medio del borde.
- Bound label de flecha puede bajar a fontSize 14 → fix-fonts + re-exportar SVG.
- Boletines: texto puro, sin imágenes ni números de unidad en títulos.
- Lenguaje es-ES obligatorio; alt texts descriptivos.
- Locks LibreOffice `docx/**/.~lock.*#` NO commitear.
- Prohibido editar `docs/informes-revision/**`, `openspec/**`.

  mal y el checker no matchea). Quitar líneas vacías del `text` en el JSON.
